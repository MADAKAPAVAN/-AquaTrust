# Dataset

The AquaTrust experiments use a publicly available side-scan sonar
object-detection dataset.

The raw dataset is NOT redistributed in this repository.

Dataset source and official download information:

- Official dataset repository: Figshare
- DOI: 10.6084/m9.figshare.24574879
- License: CC BY 4.0

Please obtain the dataset from the original source and follow the
dataset's citation and license requirements.

The experimental dataset contains:

- 1,170 side-scan sonar images
- 668 annotated bounding boxes
- 819 training images
- 175 calibration images
- 176 final evaluation images

The repository provides the experimental code, configurations,
evaluation results and documentation without redistributing the
original dataset.
